## Definition

- Per-Measurement, append-only record of every run
- The single source of truth — CLI and Console both read from it

## What a row contains

- Run identity, provenance, and reproducibility fields
- Eval results and training chunk outcomes

## Guarantees

- Append-only: rows are never rewritten
- Full provenance: any result can be traced to exact inputs

## How to read it

- `monte status <measurement>` — rows plus per-lineage delta
- Console Ledger page — same data, read-only web view
