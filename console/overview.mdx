## What the console is

- FastAPI server plus Next.js web app
- Strictly read-only — the CLI is the only write path

## Running it locally

- Starting the server
- Starting the web app
- Where it looks for ledger data

## Pages

- Ledger — measurements and their rows
- Runs — run list and run detail
- Tasks — per-task results
- Environments, Evaluations, Training views
- Live events

## API routes

- `/api/measurements`, `/api/runs`, `/api/environments`, `/api/config` and friends
