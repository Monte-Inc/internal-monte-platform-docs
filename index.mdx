## What is Monte

- One-sentence definition: the end-to-end model-improvement loop
- The contract: a Measurement goes in, a measurably better model (or an honest null result) comes out
- NeMo-native, runs on a single GPU box

## Who this is for

- Current audience: internal engineering
- What you can do with it: define measurements, run evals, train, compare, promote

## How the pieces fit together

- `monte` CLI — the primary interface
- Core / API / CLI layering — logic never prints, CLI is a thin rendering layer
- Environments — pluggable graded task packages
- Ledger — append-only record of every run, per Measurement
- Console — read-only web view over the same ledger
