## Prerequisites

- The box contract: what the GPU box must look like (GPU, NFS layout, access)
- Local tooling: Python 3.12+, uv, SSH access

## Install

- Install the `monte` package
- Verify with `monte config`

## Install an environment

- `monte env list` — discover available environments
- `monte env install` — set up box assets for an environment

## Initialize a measurement

- `monte init <measurement> --env <name>` — freeze splits, eval config, fingerprint
- What "frozen" means and why it matters

## Run a baseline eval

- `monte eval <measurement>` — eval@N against the base model
- Reading the output

## Train

- `monte train <measurement>` — one train@N chunk
- `--smoke` for a fast sanity pass
- `--chained` for continuing a lineage

## Check status

- `monte status <measurement>` — ledger rows and per-lineage delta
- `monte logs` / `monte show` for run introspection

## Promote

- `monte promote <measurement/run> --confirm=<measurement>` — what promotion does
- The honest-null case: when not to promote
