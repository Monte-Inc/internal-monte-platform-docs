---
title: "Quickstart"
description: "Your first loop on a laptop, no GPU needed"
---

Off the GPU box, every Run mocks: real CLI, real Ledger, fake scores. That makes a laptop the safe place to learn the loop.

You need [uv](https://docs.astral.sh/uv) and read access to `Monte-Inc/internal-monte-platform`. uv fetches its own Python, and you never clone the repo.

<Steps>
  <Step title="Install the CLI">
    ```bash
    uv tool install git+ssh://git@github.com/Monte-Inc/internal-monte-platform \
      --with "git+ssh://git@github.com/Monte-Inc/internal-monte-platform#subdirectory=environments/demo"
    ```
    This puts `monte` on your PATH, so every command below is bare `monte`.

    The `--with` line adds the `demo` Environment. Monte ships no Environments of its own: each one is a separate package, and installing it is what registers it. Keep the quotes around that URL.

    If your shell cannot find `monte`, run `uv tool update-shell` and open a new shell.
  </Step>
  <Step title="List the installed Environments">
    ```bash
    monte env list
    ```
    `demo` appears as mock-only. It exists to exercise the loop itself.
  </Step>
  <Step title="Create a Measurement">
    ```bash
    monte init hello --env demo
    ```
    This freezes the Splits, the eval settings, and the Environment fingerprint. The name `hello` is yours to choose.
  </Step>
  <Step title="Run the Baseline eval">
    ```bash
    monte eval hello
    ```
    The CLI prints the Run plan and asks `launch?`. The mock Run takes about 30 seconds. This is `eval@0`, the score you compare every later Run against.
  </Step>
  <Step title="Train a smoke chunk">
    ```bash
    monte train hello --smoke
    ```
    A smoke Run is a capped sanity pass. It is never evidence: it cannot be a Baseline, a chain parent, or a promote source.
  </Step>
  <Step title="Read the Ledger">
    ```bash
    monte status hello
    ```
    You get the Run rows and the Cohort's Baseline line. Smoke rows carry a `[not evidence]` marker. There is no delta yet: a delta appears after a real training chunk and its follow-up eval.
  </Step>
</Steps>

## Stay current

The beta changes quickly. Pull the newest CLI with:

```bash
uv tool upgrade monte
```

To remove it, run `uv tool uninstall monte`.

<Note>
A real score needs a GPU box, and running on one needs a checkout of the platform repo rather than this tool install. Those instructions are being rewritten and are not on this site yet.
</Note>
